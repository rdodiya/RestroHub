Normal User (customer of restaurant/normal people) Flow

he/she open url/scan qr code from table or cash counter and an link of restaurant will open which contains basic sections like
hero, description, contact , menu , add to cart option, language change dropdown
this sections data will be recive from backend (spring boot api) and react will render the template dynamically.

The link of restaurant will be like restaurantname.restroly.in as restroly.in is our domain and this dynamic config is need to perform @Todo

Now user can see website and add items from menu to cart then all items will be visible in cart and user can order it before
order user need to add mobile number and name and on successfully order placed user will get notification message on whatsapp with upi payment
link on success order (using https://github.com/vivekkushwaha66/upi-deeplink-builder) in provided number if whatsapp features is enable to that restaurant and
admin get App Notification of order and order details will be populated in Order section of admin panel.

Order status will be updated to users when admin change order status from pending , preparing, Ready ,etc.. with payment link if payment is not done and order status is ready.

Now if user scans qr from table then  the order placed will be shown for particular table in admin panel otherwise if qr is scan from counter then
the table no will default 0. As counter table qr code can be used in restaurant cards also.
